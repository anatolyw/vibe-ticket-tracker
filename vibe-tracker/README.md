# Vibe Tracker

A local ticket tracking system for vibe coders. Track all performed changes as part of your project's living documentation.

## Features

- **CLI**: `vibe-tracker init` and `vibe-tracker start`
- **REST API**: Full CRUD for tickets at `/api/tickets/*`
- **MCP Endpoints**: AI agents can create, read, update, list, and delete tickets programmatically
- **Web UI**: Angular SPA with dashboard, ticket list, detail view with markdown editor
- **Dark/Light Theme**: Toggle with persisted preference
- **Responsive**: Works on mobile (hamburger menu) through desktop (collapsible sidebar)

## Installation

```bash
npm install vibe-tracker
```

### Manual Setup (Development)

If installing from source:

```bash
# 1. Create local bin directory
mkdir -p $HOME/.local/bin

# 2. Add to PATH (add to ~/.bashrc or ~/.zshrc for persistence)
export PATH="$HOME/.local/bin:$PATH"

# 3. Symlink the CLI using an ABSOLUTE path (CRITICAL — see note below)
ln -s /absolute/path/to/your/vibe-tracker-project/bin/vibe-tracker.cjs $HOME/.local/bin/vibe-tracker
```

**⚠️ Important: Symlink must use an absolute path**

The symlink target cannot be relative (e.g., `./bin/vibe-tracker.cjs`). Symlink targets are resolved relative to the symlink's location (`$HOME/.local/bin/`), not your current working directory. So `ln -s ./bin/vibe-tracker.cjs ~/.local/bin/vibe-tracker` would resolve to `~/.local/bin/bin/vibe-tracker.cjs` — which doesn't exist.

**Correct examples** (choose the one matching your setup):

```bash
# From any directory — use the absolute path to the vibe-tracker repo
ln -s /Users/mac/workspace/vibe-tracker/bin/vibe-tracker.cjs $HOME/.local/bin/vibe-tracker

# Or if you want a project-relative symlink (works from the vibe-tracker/ directory):
ln -s $(pwd)/bin/vibe-tracker.cjs $HOME/.local/bin/vibe-tracker
```

**Verify:**

```bash
vibe-tracker        # Should show usage info
vibe-tracker init   # Should initialize in the current directory
```

## Usage

### Quick Start

```bash
# Initialize in your project
vibe-tracker init

# Start the server
vibe-tracker start

# Or use npm scripts (added automatically after init)
npm run vibe:start
npm run vibe:open   # Opens in browser
```

### Configuration

`vibe-tracker.json` (generated by `init`):

```json
{
  "VIBE_TRACKER_PORT": 61000,
  "VIBE_TRACKER_DOC_ROOT": ".vibe-tracker",
  "VIBE_TRACKER_TICKET_PREFIX": "issue",
  "VIBE_TRACKER_TICKET_TYPE_OPTIONS": ["issue", "feat", "bug"],
  "VIBE_TRACKER_TICKET_NUM_PATTERN": "XXXXX",
  "VIBE_TRACKER_TICKET_SUFFIX_LENGTH": 80
}
```

### Ticket Format

Tickets are stored as Markdown files with YAML frontmatter in `.vibe-tracker/`:

```markdown
---
id: "issue-00001"
title: "Add login page"
type: "feat"
status: "open"
created: "2025-01-15T10:30:00Z"
updated: "2025-01-15T10:30:00Z"
---

# Add login page

## Description
...
```

Filename: `issue-00001-add-login-page.md`

## API Reference

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/tickets` | List tickets with filters |
| GET | `/api/tickets/:id` | Get a single ticket |
| POST | `/api/tickets` | Create a ticket |
| PUT | `/api/tickets/:id` | Update a ticket |
| DELETE | `/api/tickets/:id` | Delete a ticket |

### Query Parameters (list)

- `status`: `open` | `closed`
- `type`: `issue` | `feat` | `bug`
- `search`: text search
- `sort`: `created` | `updated` | `title`
- `order`: `asc` | `desc`
- `limit`: number (default 50)
- `offset`: number (default 0)

## MCP Endpoints

Access AI tools at `http://localhost:61000/mcp`:

**Tools:** `vibe_tracker_create_ticket`, `vibe_tracker_update_ticket`, `vibe_tracker_delete_ticket`, `vibe_tracker_list_tickets`, `vibe_tracker_get_ticket`

**Resources:** `vibe://tickets/{id}`, `vibe://tickets/{id}/raw`, `vibe://tickets/{id}/metadata`, `vibe://tickets/`, `vibe://config`

## Development

### Build from Source

```bash
# Install dependencies
npm install

# Build server
npm run build:server

# Build Angular UI
npm run build:ui

# Or build both
npm run build

# Start the server
node dist/server/index.js
```

### Development Workflow

```bash
# Watch Angular changes
npm run build:ui -- --watch

# Watch TypeScript server changes
tsc --project tsconfig.server.json --watch
```
